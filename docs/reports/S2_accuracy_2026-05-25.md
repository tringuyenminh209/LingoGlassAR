## Decision

Manual accuracy scoring (exit criterion #4) is **deferred to S3**, paired with
the paid native-VN reviewer already planned for the S3 pilot (open question #1).
Self-scoring on device against the on-screen `Last final` was judged too
unreliable to gate on for a bilingual solo run, and the privacy rule forbids
storing the translated text for later scoring -- so a structured S3 reviewer
session is the right place for this gate.

The same run still serves as a fresh **device confirmation of latency exit
criterion #2** (`p95(system_latency_ms) <= 2000 ms`), which **PASSES**.
