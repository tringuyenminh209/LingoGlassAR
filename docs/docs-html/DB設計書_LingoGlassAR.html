■ §1　設計方針・命名規則・型ポリシー
命名規則 ・テーブル名：snake_case + 複数形（例: sessions）
・主キー：id（UUID v4）
・外部キー：[参照先単数形]_id（例: session_id）
・タイムスタンプ：created_at / updated_at（TIMESTAMPTZ）必須
・フラグ：is_ prefix（例: is_active）
・ステータス：VARCHAR + CHECK 制約（コード一覧 §5 と一致）
・ソフト削除は採用しない（プライバシー要件 NFR-08 のため物理削除）
型ポリシー ・ID：UUID（uuid_generate_v7() 推奨、移行用に gen_random_uuid() でも可）
・タイムスタンプ：TIMESTAMPTZ（UTC 保存、表示時 JST 変換）
・短いコード値：VARCHAR(20) + CHECK
・長いテキスト：TEXT（nullable）
・JSON：JSONB（インデックス可能）
・ハッシュ：CHAR(64)（SHA-256 hex）
・言語コード：VARCHAR(5)（BCP 47: ja / en / vi / ko / zh-CN）
トランザクション境界原則 1 リクエスト 1 トランザクション。WSS セッションは長時間のため イベント単位 で commit。session_events はバルク insert で性能維持
マルチテナントMVP では単一プロジェクト。将来 B2B 対応時に org_id 列追加 + RLS を導入（Rev 2.x で計画）
プライバシー設計 ・sessions.retain_text=false なら session_events.payload_text は NULL のまま
・ocr_requests は画像本体を保存せず SHA-256 ハッシュのみ
・テスター匿名化：パイロット終了 + 90 日で testers.nickname を 'anon-{uuid8}' に更新

■ §3　テーブル一覧 + リテンションポリシー
Noテーブル名区分主用途保持期間 / アーカイブ方針
1devicesマスタペアリング済みグラス無期限。is_active=false で論理停止、物理削除なし
2testersマスタパイロット参加者パイロット終了 + 90 日で匿名化（nickname を上書き）
3sessionsトランザクション会話セッション90 日。日次 dump → B2 ストレージ。それ以降 cron で物理削除
4session_eventsトランザクション各ステップ遅延ログ30 日。月次で集計 → latency_summary_{month} マテビューに集約
5ocr_requestsトランザクションOCR リクエスト履歴30 日。画像本体は保存しない（hash のみ）
6error_logsトランザクションエラー / 警告ログ30 日。severity=critical のみ 1 年保持
7feedbackトランザクションパイロットフィードバック無期限（匿名化後 Go/No-Go レポートに使用）

■ §4.1　テーブル定義書 — マスタ
4.1.1　devices（ペアリング済みグラス）
No列名型NULLデフォルト区分説明 / 制約
1idUUIDNOgen_random_uuid()PK主キー。クライアントは X-Device-Id ヘッダで送信
2device_typeVARCHAR(30)NO'prototype_v1'—CHECK IN ('prototype_v1', 'prototype_v2')
3firmware_versionVARCHAR(20)NO'0.0.0'—セマンティックバージョニング（例: 0.1.3）
4ble_macVARCHAR(17)NO—UQ形式: AA:BB:CC:DD:EE:FF。UNIQUE INDEX
5is_activeBOOLNOtrue—false でペアリング解除（FR-APP-09）
6last_seen_atTIMESTAMPTZYESNULL—最後の WSS / BLE heartbeat
7created_atTIMESTAMPTZNONOW()—レコード作成日時
8updated_atTIMESTAMPTZNONOW()—更新トリガで自動更新
インデックス：PRIMARY KEY (id) ／ UNIQUE INDEX devices_ble_mac_uq (ble_mac) ／ INDEX devices_last_seen_idx (last_seen_at DESC) WHERE is_active=true（部分インデックス）
4.1.2　testers（パイロット参加者）
No列名型NULLデフォルト区分説明 / 制約
1idUUIDNOgen_random_uuid()PK主キー
2nicknameVARCHAR(50)NO——表示用ニックネーム。匿名化後は anon-{uuid8} に上書き
3segmentVARCHAR(20)NO——CHECK IN ('tourist','student','staff','business')
4ui_languageVARCHAR(5)NO'ja'—CHECK IN ('ja','en','vi')
5recruited_atDATENOCURRENT_DATE—パイロット参加日
6anonymized_atTIMESTAMPTZYESNULL—匿名化済日時。NULL = まだ匿名化していない
7created_atTIMESTAMPTZNONOW()——
8updated_atTIMESTAMPTZNONOW()——
インデックス：PRIMARY KEY (id) ／ INDEX testers_segment_idx (segment)（パイロットレポート集計用）
補足：マスタテーブル運用ルール
  • 更新頻度：devices は週次（新規ペアリング時）、testers はパイロット期間のみ
  • キャッシュ可否：両テーブルとも 1 時間 Redis にキャッシュ可（メモリ消費 1MB 未満）
  • 削除ポリシー：物理削除しない。devices.is_active / testers.anonymized_at で論理管理
  • 監査：UPDATE はトリガで updated_at 自動更新。重要な状態変化は error_logs に severity=info で記録

4.2.2　session_events（各ステップの遅延ログ）
No列名型NULLデフォルト区分説明 / 制約
1idUUIDNOgen_random_uuid()PK—
2session_idUUIDNO—FKREFERENCES sessions(id) ON DELETE CASCADE
3seq_noINTNO——セッション内の連番（1 から）
4event_typeVARCHAR(30)NO——CHECK IN ('vad_start','vad_end','stt_done','translate_done','ble_sent','displayed','error')
5duration_msINTYESNULL—当該ステップの所要ms。最初の event は NULL 可
6payload_textTEXTYESNULL—翻訳テキスト等。sessions.retain_text=true 時のみ保存
7metadataJSONBYES'{}'—provider 名・MTU・サンプリングレート等
8created_atTIMESTAMPTZNONOW()——
インデックス：PRIMARY KEY (id) ／ UNIQUE INDEX se_session_seq_uq (session_id, seq_no)（同一連番の重複防止）／ INDEX se_event_type_idx (event_type) ／ INDEX se_session_created_idx (session_id, created_at)（p50/p95 集計用）
パフォーマンス考慮：session_events は最も書込が多い（1 セッション × 約 5 イベント × 10 発話 = 50 行）。COPY または INSERT ... VALUES (..),(..) のバルク挿入で 1 トランザクション化。月次で latency_summary_{YYYY-MM} マテビューに集約後、原本は削除可。

■ §7　DDL サンプル（PostgreSQL 16）
-- 拡張機能（UUID v7 推奨。なければ random で代替）
CREATE EXTENSION IF NOT EXISTS pgcrypto;

-- マスタ：devices
CREATE TABLE devices (
  id               UUID         PRIMARY KEY DEFAULT gen_random_uuid(),
  device_type      VARCHAR(30)  NOT NULL DEFAULT 'prototype_v1'
                                CHECK (device_type IN ('prototype_v1','prototype_v2')),
  firmware_version VARCHAR(20)  NOT NULL DEFAULT '0.0.0',
  ble_mac          VARCHAR(17)  NOT NULL UNIQUE,
  is_active        BOOLEAN      NOT NULL DEFAULT true,
  last_seen_at     TIMESTAMPTZ,
  created_at       TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
  updated_at       TIMESTAMPTZ  NOT NULL DEFAULT NOW()
);
CREATE INDEX devices_last_seen_idx ON devices (last_seen_at DESC) WHERE is_active = true;

-- マスタ：testers（パイロット参加者、匿名化前提）
CREATE TABLE testers (
  id            UUID         PRIMARY KEY DEFAULT gen_random_uuid(),
  tester_code   VARCHAR(30)  NOT NULL UNIQUE,
  segment       VARCHAR(20)  NOT NULL CHECK (segment IN ('tourist','student','staff','business')),
  ui_language   VARCHAR(5)   NOT NULL DEFAULT 'ja' CHECK (ui_language IN ('ja','en','vi')),
  consent_at    TIMESTAMPTZ  NOT NULL,
  anonymized_at TIMESTAMPTZ,
  created_at    TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
  updated_at    TIMESTAMPTZ  NOT NULL DEFAULT NOW()
);
CREATE INDEX testers_segment_idx ON testers (segment);

-- トランザクション：sessions
CREATE TABLE sessions (
  id           UUID         PRIMARY KEY DEFAULT gen_random_uuid(),
  device_id    UUID         NOT NULL REFERENCES devices(id) ON DELETE RESTRICT,
  tester_id    UUID         REFERENCES testers(id) ON DELETE SET NULL,
  source_lang  VARCHAR(5)   NOT NULL CHECK (source_lang IN ('ja','en','vi','ko','zh-CN')),
  target_lang  VARCHAR(5)   NOT NULL CHECK (target_lang IN ('ja','en','vi','ko','zh-CN')),
  status       VARCHAR(20)  NOT NULL DEFAULT 'active'
                            CHECK (status IN ('active','ended','error')),
  retain_text  BOOLEAN      NOT NULL DEFAULT false,
  started_at   TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
  ended_at     TIMESTAMPTZ,
  created_at   TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
  updated_at   TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
  CONSTRAINT sessions_lang_diff CHECK (source_lang <> target_lang)
);
CREATE INDEX sessions_device_started_idx ON sessions (device_id, started_at DESC);
CREATE INDEX sessions_tester_idx ON sessions (tester_id) WHERE tester_id IS NOT NULL;
CREATE INDEX sessions_status_idx ON sessions (status) WHERE status = 'active';

-- トランザクション：session_events（最も書込が多い）
CREATE TABLE session_events (
  id           UUID         PRIMARY KEY DEFAULT gen_random_uuid(),
  session_id   UUID         NOT NULL REFERENCES sessions(id) ON DELETE CASCADE,
  seq_no       INTEGER      NOT NULL,
  event_type   VARCHAR(30)  NOT NULL CHECK (event_type IN
                  ('vad_start','vad_end','stt_done','translate_done','ble_sent','displayed','error')),
  duration_ms  INTEGER,
  payload_text TEXT,
  metadata     JSONB        NOT NULL DEFAULT '{}',
  created_at   TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
  UNIQUE (session_id, seq_no)
);
CREATE INDEX se_event_type_idx ON session_events (event_type);
CREATE INDEX se_session_created_idx ON session_events (session_id, created_at);

-- トランザクション：ocr_requests（画像本体は保存しない）
CREATE TABLE ocr_requests (
  id              UUID         PRIMARY KEY DEFAULT gen_random_uuid(),
  device_id       UUID         NOT NULL REFERENCES devices(id) ON DELETE RESTRICT,
  image_hash      CHAR(64)     NOT NULL,
  source_lang     VARCHAR(5)   NOT NULL CHECK (source_lang IN ('auto','ja','en','vi','ko','zh-CN')),
  target_lang     VARCHAR(5)   NOT NULL CHECK (target_lang IN ('ja','en','vi','ko','zh-CN')),
  ocr_text_length INTEGER,
  status          VARCHAR(20)  NOT NULL DEFAULT 'pending' CHECK (status IN ('pending','success','failed')),
  duration_ms     INTEGER,
  created_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
  CONSTRAINT ocr_lang_diff CHECK (source_lang = 'auto' OR source_lang <> target_lang)
);
CREATE INDEX ocr_device_created_idx ON ocr_requests (device_id, created_at DESC);
CREATE INDEX ocr_status_idx ON ocr_requests (status) WHERE status = 'failed';

-- トランザクション：error_logs
CREATE TABLE error_logs (
  id          UUID         PRIMARY KEY DEFAULT gen_random_uuid(),
  device_id   UUID         REFERENCES devices(id) ON DELETE SET NULL,
  session_id  UUID         REFERENCES sessions(id) ON DELETE SET NULL,
  severity    VARCHAR(20)  NOT NULL CHECK (severity IN ('info','warn','error','critical')),
  error_code  VARCHAR(50)  NOT NULL,
  message     TEXT         NOT NULL,
  context     JSONB        NOT NULL DEFAULT '{}',
  created_at  TIMESTAMPTZ  NOT NULL DEFAULT NOW()
);
CREATE INDEX err_severity_created_idx ON error_logs (severity, created_at DESC);
CREATE INDEX err_session_idx ON error_logs (session_id) WHERE session_id IS NOT NULL;
CREATE INDEX err_context_gin ON error_logs USING GIN (context);

-- トランザクション：feedback（パイロット評価）
CREATE TABLE feedback (
  id              UUID         PRIMARY KEY DEFAULT gen_random_uuid(),
  tester_id       UUID         REFERENCES testers(id) ON DELETE SET NULL,
  session_id      UUID         REFERENCES sessions(id) ON DELETE SET NULL,
  rating          INTEGER      CHECK (rating BETWEEN 1 AND 5),
  would_recommend VARCHAR(10)  NOT NULL CHECK (would_recommend IN ('yes','no','maybe')),
  comment         TEXT,
  created_at      TIMESTAMPTZ  NOT NULL DEFAULT NOW()
);
CREATE INDEX fb_tester_idx ON feedback (tester_id);
CREATE INDEX fb_created_idx ON feedback (created_at DESC);

-- updated_at 自動更新トリガ（共通関数）
CREATE OR REPLACE FUNCTION set_updated_at() RETURNS TRIGGER AS $$
BEGIN NEW.updated_at = NOW(); RETURN NEW; END; $$ LANGUAGE plpgsql;

CREATE TRIGGER devices_updated_at  BEFORE UPDATE ON devices  FOR EACH ROW EXECUTE FUNCTION set_updated_at();
CREATE TRIGGER testers_updated_at  BEFORE UPDATE ON testers  FOR EACH ROW EXECUTE FUNCTION set_updated_at();
CREATE TRIGGER sessions_updated_at BEFORE UPDATE ON sessions FOR EACH ROW EXECUTE FUNCTION set_updated_at();
