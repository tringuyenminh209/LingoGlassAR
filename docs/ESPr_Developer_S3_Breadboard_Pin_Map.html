OLED VCC

Connect to left row 11, +3V3. Do not use VIN for the first test.

OLED GND

Connect to left row 19 or row 30 GND. Any GND pin is common.

OLED SCL

Connect to left row 18, IO9. Code uses GPIO 9 for SCL.

OLED SDA

Connect to left row 21, IO8. Code uses GPIO 8 for SDA.
