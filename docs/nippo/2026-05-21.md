## 課題・懸念

- **`websockets` v13.x lock-in リスク**。OpenAI Realtime SDK が成熟したら
  raw `websockets` から SDK 経由に切替検討。今は SDK 側 Realtime WS が
  まだ不安定との Codex 観察を信頼。
- **Day 3 WS endpoint のテスト戦略**。実 Redis を使わない方針 (fake で
  HSET/EXPIRE/HGETALL を記録) は Day 1 と整合。実 Redis を使う統合テスト
  は Day 4 (EC2 デプロイ) 直前に手動 smoke のみで済ます予定。
- **`/api/v1/*` vs `/v1/*` の prefix 二重化**。当面 S2 で統合とドキュメント
  化したが、Day 7 で mobile から呼び始めるとき混乱しないよう mobile 側で
  base URL 定数を 1 箇所にまとめる必要あり。
