### Day 4 中に発生した 2 件の incident

#### Incident 1: 521 (port 80 にバインドしていない)

最初の deploy では `docker-compose.yml` の ports が `8000:8000` 固定。
Cloudflare は port 80 にしかつなぎに来ないので 521 発生。

修正 (`f187a45`): `API_HOST_PORT` 環境変数化。`.env` で `API_HOST_PORT=80`
を指定すれば compose は 80:8000 にバインド。ローカル dev は default 8000。

#### Incident 2: 521 (SSL/TLS モード Full)

修正後も 521 が続く。原因: 当初 runbook に `SSL/TLS = Full` と書いてい
たが、Full は CF → origin が HTTPS port 443。我々の origin は HTTP port 80
のみで 443 listener なし → 521。

修正 (`fdaa739`): Cloudflare SSL/TLS を **Flexible** に切替。drawio
バッジと runbook を Flexible に更新。memory に
`cloudflare-ssl-mode.md` を保存して将来の再発を防止。

### Day 4 学び

1. **Cloudflare SSL モードの意味を取り違えていた**。"Full" は CF→origin
   が HTTPS という意味で、HTTP-only origin には Flexible が正解。memory

   わせが想像以上に楽。VPC/Subnet/KeyPair が全部ドロップダウン enumerate
