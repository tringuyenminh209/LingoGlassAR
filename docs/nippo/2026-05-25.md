## 追記: Day 7 prep — origin TLS リバースプロキシの stub＋runbook (2026-05-25)

Day 6 クローズ後そのまま Day 7（Cloudflare Full(Strict) 準備）の Claude prep 分に着手。

### 1. cert 方針を確定（criterion #5 の前提）
open question #3 の「Let's Encrypt」を実装レベルで確定: **DNS-01 challenge** を採用。
理由 — `api` レコードが orange-cloud（proxied）なので HTTP-01 challenge は
Cloudflare エッジに当たって origin に届かず失敗する。DNS-01 なら Cloudflare API
token でゾーン所有を証明でき proxy の影響を受けない。Origin Cert は直 origin の
デバッグ（CF バイパス）で証明書検証が通らなくなるため不採用。

### 2. `bootstrap.sh` に nginx リバースプロキシ stub をロック
- 関数 3 本（`install_tls_proxy` / `issue_origin_cert` /
  `configure_nginx_reverse_proxy`）を `:` no-op ＋ 詳細 TODO コメントで定義。
- env: `LINGOGLASS_TLS_PROXY`(既定 0=OFF) / `ORIGIN_HOSTNAME` /
  `CF_DNS_CREDENTIALS_FILE` / `BACKEND_UPSTREAM`(既定 127.0.0.1:8000)。
- 既定 OFF ガードで未設定時は S1 Flexible のまま挙動不変＝再実行も冪等。
- `bash -n` 構文 OK。body は Codex 実装（prep/impl 軸: infra stub は安全に
  stub 化できるので Codex impl が妥当）。
