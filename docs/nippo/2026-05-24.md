## 本日の作業内容

### 1. ベンチ用フレーズカタログ作成
`mobile/lib/data/s2_phrases.dart` を新規作成。旅行ドメインの短文 60 件:
- 日本語 30 件 (sourceLang `ja` → vi) ＋ ベトナム語 30 件 (sourceLang `vi` → ja)
- 6 ドメイン (greetings / directions / food / transit / payment / emergencies) × 各 5 件 × 2 方向
- S1 カタログと同じく一文の短文に揃え、STT レイテンシと精度を比較可能な入力にした
- `targetLang` は `sourceLang` の反対を返す getter（保存しない）

### 2. ラン・エンジンの汎用化（S1-Run-10 → S2-Run-30 共通化）
当初計画では「S1 ボタンを拡張＋ボタン本体は Codex 実装」だったが、稼働中の
S1 ラン・エンジンを stub にすると S1 ベンチが壊れること、および no-duplicate
ルール上 S2 用に並行エンジンを作れないことから、prep 側でエンジンを 1 本に
汎用化する判断にした（Day 4 cooldown と同じ prep/impl 軸）。

- `RunPhrase` typedef ＋ `_s1RunItems()` / `_s2RunItems()` ビルダーを追加し、
  両カタログをフラットなリストに平坦化
- `_s1*` 系フィールド/メソッドを汎用の `_runItems` / `_runLabel` /
  `_runActive` / `_runIndex` ＋ `_currentRunPhrase` / `_startRun(items,label)` /
  `_armRunPhrase` / `_scheduleRunAdvance` に置換
- `S2 Run 30` ボタンを `S1 Run 10` の隣に追加。両者とも `_startRun(...)` を呼び、
  `_runActive` 中は無効化
- `_onPressDown` で各フレーズの `sourceLang` / `targetLang` を `_ws.connect` に
  渡すよう配線（`TranslatorWs.connect` は元から両方向サポート済み、ラン外の手動
  PTT は従来どおり ja→vi デフォルト）

### 3. CSV スキーマに手動採点列を追加

スプレッドシート上で手採点する想定。翻訳テキスト自体は privacy ルール上 CSV に
