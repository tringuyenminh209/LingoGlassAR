以下に下げる必要 = ≥ 284 ms (32 %) 削減。

### 3. OpenAI Realtime knobs 棚卸し

WebSearch で確認した GA Realtime API の新ノブ:

- **`gpt-realtime-whisper`**: 2026-05-08 にリリースされた streaming-first
  STT モデル。partial latency 200-400 ms。現在使用中の `whisper-1` は
  finished audio 用なので streaming に最適化されていない。
- **`audio.input.transcription.delay`**: 新パラメータ。`minimal` / `low` /
  `medium` / `high` / `xhigh` の 5 段階で latency/accuracy をトレードオフ。
  `gpt-realtime-whisper` 専用。
- **`turn_detection`**: 未設定 = default の `server_vad` が動作。PTT で
  manual `input_audio_buffer.commit` しているので server VAD は無駄推論。
  `null` で無効化可能。
- **`response.create` の `instructions`**: PR #2 review で指摘済みの
  `session.update` との重複。トークナイズ ~50 ms 損。
